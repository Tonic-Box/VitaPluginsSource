# Vita Multi-Client Util
Has your other logged-in VitaLite clients act together, from a side panel or from right-click menus.
- **Come Here**: every client hops to this client's world and walks to where you stand
- **DD**: clients nearby walk onto your tile
- **Follow**: clients nearby follow you
- **Scatter**: clients nearby walk to random tiles around you
- **Cat Fact**: every client says a cat fact in public chat

### Extended Menus
Switch on **Extended Menus** in the panel to add options to right-click menus. Each one does the action on this client and has the other clients do it too.
- **(Nearby) Walk Here** and **(All) Pathfind Here** on the ground
- **(Nearby)** versions of an object's options, for clients near that object
- **(All)** versions of NPC and player options

### How to use
1. Install and enable the plugin on every client that should take part. Clients without it ignore the others.
2. Log the clients in. They find each other on their own once logged in, and only clients on the same computer or local network can reach each other.
3. Open the **Multi-Client Utils** panel from the sidebar.
