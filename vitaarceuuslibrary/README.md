# Vita Arceuus Library
Plays the Arceuus Library minigame for you: takes book requests, finds the books, hands them in and reads the rewards for Magic or Runecraft XP.

### How to use
Enable the plugin and switch on **Run**. Start anywhere; it walks to the library if needed.

### Settings
- **XP**: Magic, Runecraft, lowest, or random.
- **Read rewards**: after each hand-in, or when space is needed.
- **Efficient mode**: Off, Small detours (grab nearby spare books), or Stock up (carry every book).
- **Max detour** / **Restock at**: tune the efficient modes.
